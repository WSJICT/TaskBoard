# Flowline 任务看板

Flowline 是一个面向个人与小型团队的任务管理看板应用，采用 Linear Aesthetic 深色精密风格，用「待办 / 进行中 / 待验收 / 已完成」四列组织工作流，帮助使用者把复杂项目拆成清晰的下一步。

## 核心能力

- **看板工作流**：四列状态流转，支持拖动卡片跨列移动与列内排序。
- **任务管理**：创建、编辑、删除任务，可设置优先级（P0–P3）、截止日期与标签。
- **快速检索**：按标题、描述、标签搜索，并按优先级筛选。
- **进度洞察**：实时统计任务总量、进行中数量、逾期数量与完成率。
- **本地持久化**：数据自动保存在浏览器 localStorage，刷新页面不丢失。
- **效率交互**：按 `N` 快速新建任务，`Esc` 关闭编辑弹窗。

## 技术栈

| 层 | 选型 |
|---|---|
| 构建工具 | Vite 7 |
| 视图框架 | React 19 |
| 语言 | TypeScript 5（严格模式） |
| 样式 | 原生 CSS（CSS 变量、玻璃拟态、渐变光晕） |

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/` 即可使用。

生产构建：

```bash
npm run build
npm run preview
```

## 设计说明

界面以近黑色画布为底，叠加环境光晕与网格纹理；卡片使用 1px 微描边、顶部高光与悬停光扫，强调色靛蓝 / 紫罗兰仅用于交互高亮。整体追求精确、克制、低光环境友好的视觉体验，并适配 `prefers-reduced-motion` 与移动端布局。
